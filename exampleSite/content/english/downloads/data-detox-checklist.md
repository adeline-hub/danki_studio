\## Data Detox Checklist



Not sure where to start with your data cleanup?



This one-page checklist walks you through the four essential steps of data minimalism:



\### What's Inside



\*\*Audit\*\* — Know what you have

\- Map all storage locations

\- Calculate total data volume

\- Identify access permissions



\*\*Clean\*\* — Remove the noise

\- Flag duplicates and old versions

\- Archive or delete unused data

\- Secure sensitive information



\*\*Organize\*\* — Create clarity

\- Establish naming conventions

\- Structure logical folder hierarchies

\- Document metadata



\*\*Maintain\*\* — Keep it lean

\- Assign data ownership

\- Schedule regular reviews

\- Track storage costs
